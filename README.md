# 100マス計算

たし算・ひき算・かけ算の100マス計算に取り組める、小学生向けのWeb教材です。

## 公開ページ

[100マス計算を開く](https://tt-sensei.github.io/hyakumasu/)

## できること

- 100マス、50マス、30マスから選んで練習する
- たし算・ひき算・かけ算に取り組む
- タブレット向けの数字キーパッドで入力する
- タイム、正答率、ミスを確認する
- 間違えた問題だけ復習する
- 新しい問題でもう一度挑戦する
- 学習記録や自己ベストを確認する
- プリントを作成・印刷する
- 経験値やレベル、バッジを確認する

## 学習の流れ

1. マスの数と計算の種類を選ぶ
2. 問題に答える
3. 結果と自己ベストを確認する
4. ミス復習や再挑戦に取り組む
5. 学習記録を振り返る

## 動作について

- ブラウザだけで動作します
- 学習記録は利用している端末のブラウザ内に保存されます
- パソコン、タブレットで利用できます
