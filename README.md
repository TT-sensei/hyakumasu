# 100マス計算

たし算・ひき算・かけ算を練習し、正確さとタイムの変化を自分で振り返るための、小学生向けWeb教材です。

## 公開ページ

[100マス計算を開く](https://tt-sensei.github.io/hyakumasu/)

## できること

- 100マス・50マス・30マスから練習量を選べる
- たし算・ひき算・かけ算を練習できる
- タブレット向けの数字キーパッドで入力できる
- 正解・入力ミス・未入力を分けて結果を確認できる
- その回の間違いと、くり返し間違えた計算を復習できる
- 計算の種類・マス数ごとにタイムと正答率の推移を確認できる
- 全問正解の自己ベストを記録できる
- バッジ・レベルなど、続けるための仕組みがある
- 選択中の条件で問題プリントと答えを作成できる

## 学習の流れ

1. マス数と計算の種類を選ぶ
2. 数字を入力して計算する
3. 正解・間違い・未入力を確認する
4. 間違えた問題や、くり返し間違えた計算を復習する
5. 同じ条件の記録を振り返り、再挑戦する

## 記録とプライバシー

- 学習記録は利用中のブラウザ内に保存されます。
- 記録は別の端末やブラウザとは自動で共有されません。
- ブラウザのサイトデータを消去すると、保存された記録も消える場合があります。
- サーバーや外部APIへの学習データ送信は行いません。
